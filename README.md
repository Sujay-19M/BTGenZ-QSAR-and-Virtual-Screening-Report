# 🔬 About the Project

The **BTGenZ QSAR & Virtual Screening Report** is an interactive scientific reporting project designed to present a complete **Quantitative Structure–Activity Relationship (QSAR)** and **virtual screening** workflow.

The project brings together molecular data preparation, descriptor analysis, QSAR modelling, model validation, applicability-domain assessment, activity prediction, and virtual screening into a structured computational drug-discovery workflow.

Instead of presenting QSAR results only through spreadsheets, statistical outputs, or static plots, the project provides an interactive web-based environment where users can explore the analysis and scientific results directly through a browser.

# 🧪 What Does This Project Do?

The project is designed to take molecular activity data through a structured QSAR workflow and extend the analysis toward prospective compound evaluation and virtual screening.

The overall workflow can be represented as:

```text
Molecular Dataset
       ↓
Dataset Preparation & QC
       ↓
Molecular Descriptors
       ↓
Exploratory Analysis
       ↓
Feature Selection / Reduction
       ↓
QSAR Modelling
       ↓
Model Validation
       ↓
Applicability Domain
       ↓
External Validation
       ↓
Activity Prediction
       ↓
Virtual Screening
       ↓
Candidate Ranking & Analysis
