## About the Project

This project presents an interactive computational analysis focused on **BRAF-targeted drug discovery**, combining QSAR modelling, molecular analysis, virtual screening and molecular docking results into a client-facing scientific report.

The report is designed to make computational drug-discovery results easier to explore through interactive tables, molecular visualisation, model evaluation and structural analysis.

---

## 🔬 Analysis Included

- QSAR modelling
- Dataset and molecular analysis
- Model performance evaluation
- Applicability-domain analysis
- Compound ranking
- Virtual screening
- Molecular docking
- Docking score analysis
- Ligand efficiency analysis
- Protein-ligand interaction analysis
- External validation
- Read-across analysis
- Interactive molecular visualisation
- Computational drug-discovery reporting
